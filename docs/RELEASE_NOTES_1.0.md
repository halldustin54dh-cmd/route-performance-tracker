# Route Performance Tracker 1.0 — Release Notes Draft

Route Performance Tracker 1.0 introduces the complete route-tracking foundation for delivery drivers: fast checkpoints, finish-time forecasting, documented delays/events, evidence capture, route difficulty, history, analytics, AI-assisted screenshot analysis, accounts, cloud backup/restore, and optional Pro subscriptions.

Free remains useful for day-to-day route tracking and includes basic analytics plus a limited monthly AI allowance for signed-in users. Pro expands AI usage, advanced historical analytics, cloud features, and deeper reporting.
