# 14-day closed test plan

## Goal
Validate reliability, usability, AI extraction, route forecasting, account/cloud behavior, and subscription entitlement before requesting production access.

## Suggested coverage
Days 1–3: install/onboarding/accounts/core route workflow.
Days 4–6: screenshot import/AI analysis and Free quota behavior.
Days 7–9: route history/analytics/events/evidence/offline behavior.
Days 10–11: Google Play test purchase, Pro unlock, restore, cloud backup/restore.
Days 12–13: regression testing after fixes.
Day 14: confirm testers remain opted in, collect final feedback, prepare production-access summary.

Testers do not need to use the app every day, but several meaningful sessions are preferred.
