# Google Play listing draft

## App name
Route Performance Tracker

## Short description
Track delivery routes, delays, finish forecasts, evidence, and performance trends.

## Full description
Route Performance Tracker helps delivery drivers understand and document the work behind every route.

Track your route with quick checkpoints, record delays and real-world events, monitor your pace, and get an estimated finish time as the day develops. Save route evidence and build a personal history that shows how workload, route type, travel, and interruptions affect performance.

Route screenshots can be imported for assisted analysis. Supported screenshots may help populate route information from pick sheets, itineraries, and route maps. Always review extracted information before relying on it.

Core features include:
• Fast route and checkpoint logging
• Finish-time forecasting
• Delay and event documentation
• Evidence photos and screenshots
• Route difficulty and performance metrics
• Route history and analytics
• Optional accounts and cloud features
• AI-assisted route screenshot analysis

Free includes the core route tracker and a limited number of AI analyses. Route Performance Tracker Pro adds expanded AI analysis, advanced analytics and forecasting, cloud features, and enhanced reporting.

Route Performance Tracker is an independent productivity tool. It is not affiliated with, endorsed by, or provided by Amazon, any delivery service provider, or any employer.
