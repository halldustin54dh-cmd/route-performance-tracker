# Release handoff summary

The repository is prepared to automate application tests, debug APK generation, and a signed release AAB once Android upload-signing secrets exist in GitHub. Store product creation, Play API credentials, final Vercel payment-verification secrets, policy URL publication, Play Console declarations, and closed-track publication require owner-controlled external accounts.

Do not mark 1.0 ready for closed testing until every unchecked item in RELEASE_CHECKLIST.md has been verified or explicitly deferred with user-visible wording that matches actual behavior.
