# Store review notes

If Google Play reviewers need context:
- The app is an independent delivery-driver productivity tool.
- It does not connect to or impersonate Amazon/DSP systems.
- AI screenshot analysis is user-initiated and requires review before applying extracted values.
- Core route tracking works locally without an account.
- Accounts are used for AI quota, cloud features, and subscription restoration.
- Purchases are verified server-side before Pro entitlement is granted.
