# Tester invitation message template

I'm testing a new Android app called Route Performance Tracker. It's built for delivery drivers to track route pace, forecast finish time, document delays/evidence, analyze route screenshots, and build a personal performance history.

Google requires a closed test before the app can be released publicly. If you join, please stay opted in for the full testing period and use the app a few times if you can. You do not need to be a delivery driver to help; account setup, screenshot import, navigation, backup/restore, and general usability all need testing too.

Beta access is for testing only. Do not upload sensitive customer/employer information you are not authorized to store or process.

I'll provide the Google Play opt-in link and the short Beta Tester Guide when the closed test opens.
